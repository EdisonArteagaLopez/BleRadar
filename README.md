# BleRadar

Android app that scans and visualizes nearby Bluetooth Low Energy (BLE) devices in a radar-style UI.

## Features
- BLE device scanning
- Signal strength (RSSI) display
- Radar-style visualization
- Device filtering

## Requirements
- Android Studio
- Android SDK 21+
- Device with BLE support

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/BleRadar.git
```
Open in Android Studio → Build → Run
